# تقويم الزهراء - تطبيق أندرويد

تطبيق أصلي (Kotlin) لتقويم الزهراء ١٤٤٨هـ - الأحساء.

- `app/src/main/assets/calendar.json`: بيانات السنة كاملة (٣٥٤ يوماً) منقولة من ملف التقويم الرسمي: المواقيت، التواريخ (الزهراء / أم القرى / الميلادي)، ألوان الأيام، المناسبات بألوانها، عقد النكاح، السكن، الحجامة، الطالع، القبلة، السحور.
- تنبيهات الأذان (الصبح، الظهر، المغرب، وغيرها اختيارياً) وإشعار مناسبة اليوم.
- ودجت للشاشة الرئيسية مع العد التنازلي للوقت القادم.
- التحديث: التطبيق يقرأ `release/latest.json`؛ عند رفع نسخة جديدة يظهر للمستخدم «تحديث جديد متوفر».

## إصدار تحديث
1. ارفع `versionCode` و `versionName` في `app/build.gradle.kts`.
2. `gradle assembleRelease` (يحتاج `keystore.properties` ومفتاح التوقيع نفسه، وإلا لن يقبل الجوال التحديث).
3. انسخ `app/build/outputs/apk/release/app-release.apk` إلى `release/taqweem-alzahra.apk` وحدّث `release/latest.json`.
